# Resume Bullet Improver

A simple React project that improves basic resume bullet points into more professional-sounding statements.

## Features

- Enter a resume bullet point
- Improve the button to generate enhanced text
- Clear button to reset input and output
- Simple dark-themed UI
- Built using basic React concepts

## Concepts Used

- React
- useState
- Event handling
- Conditional rendering
- CSS styling

## Tech Stack

- React
- Vite
- JavaScript
- CSS
